# Attribution

Most of this kit is other people's generous work. Here's exactly whose, where it came from, what license it's under, and what we changed. If a file isn't on this list or made by us, it doesn't belong here.

## Third-party parts

Each folder is a straight copy of the upstream part, with a tidier folder name. Where the upstream only had a STEP file, we added an STL converted from that STEP (same geometry, same units, millimeters) so it works in Tinkercad and slicers. Those converted STLs carry the same license as the STEP they came from.

## Not included on purpose

- **Seeed XIAO ESP32S3 and XIAO ESP32S3 Sense.** Seeed publishes 3D models but doesn't put a license on them, so we link instead of copying. Get them from the [Seeed wiki](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/).
- **Adafruit's Fusion 360 originals (`.f3d`).** They're upstream in [Adafruit_CAD_Parts](https://github.com/adafruit/Adafruit_CAD_Parts). The one exception is the mini arcade button, which only exists upstream as Fusion files.
